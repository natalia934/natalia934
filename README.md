###  About Me

I'm **Nathalia Santos**, a Computer Science student at **PUC Goiás** — first semester, fully committed to becoming a solid **Backend Developer**.

From day one I've been focused on building a strong technical foundation. I work with **Java** for object-oriented design and backend logic, and **C** to understand how things work at the systems level — memory, pointers, performance. That low-level thinking is what separates good backend engineers from great ones.

I don't just study theory. I build projects, solve problems, and push code consistently. My goal is clear: **land my first backend role**, contribute to real systems, and grow fast inside a team that values clean, efficient code.
